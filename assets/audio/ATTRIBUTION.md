# Audio assets

The card and casino-chip effects in this directory are selected from **Kenney Casino Audio**, released under **CC0 1.0**.

- Source: https://kenney.nl/assets/casino-audio
- Mirror used for the asset archive: https://opengameart.org/content/54-casino-sound-effects-cards-dice-chips
- License: https://creativecommons.org/publicdomain/zero/1.0/

Files were renamed for their in-game purpose and transcoded to MP3 for wider mobile-browser support. The turn, countdown, and victory cues are synthesized at runtime with the Web Audio API and do not use external recordings.
